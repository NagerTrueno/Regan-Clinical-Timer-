Regan Clinical & Research Timer — PWA V1.1

Files to upload together to GitHub Pages:
- index.html
- manifest.webmanifest
- service-worker.js
- icon-192.png
- icon-512.png

Important:
Upload all five files to the ROOT of the same GitHub repository.
Do not upload the ZIP itself as the website content.

After GitHub Pages is enabled, open the HTTPS Pages URL in Safari on iPad.
Then Share > Add to Home Screen > Open as Web App > Add.

The app shell is cached for offline use after it has been opened successfully once.
Project settings are stored locally in the browser/device using localStorage.
Export important session data as CSV regularly.
